# Lógica Computacional 1 - UnB 🎓

Repositório dedicado aos exercícios práticos e demonstrações da disciplina de Lógica Computacional 1 do curso de Licenciatura em Computação da Universidade de Brasília.

## 🎯 Objetivo
Este espaço documenta o progresso na construção e reconhecimento de provas formais, traduzindo o raciocínio matemático de dedução natural para a verificação mecânica rigorosa no assistente de provas Rocq (antigo Coq)[cite: 6]. 

## 📚 Conteúdos Abordados
Os scripts e exercícios aqui versionados acompanham o plano de ensino da disciplina, cobrindo:
* **Sintaxe e Semântica:** Estudo aplicado à lógica proposicional e à lógica de primeira ordem[cite: 6].
* **Dedução Natural:** Construção de árvores de prova para sistemas lógicos intuicionistas e clássicos[cite: 6].
* **Verificação Formal:** Implementação de táticas para garantir a ausência de falhas nos argumentos construídos[cite: 6].

## 🛠️ Tecnologias Utilizadas
* [Rocq Prover](https://rocq-prover.org/)
* Extensão VsRocq (Visual Studio Code)
